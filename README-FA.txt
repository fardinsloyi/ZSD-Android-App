پروژه اپلیکیشن اندروید ZSD
===========================

این پروژه یک اپلیکیشن اندروید با رابط اختصاصی مشکی/طلایی و راست‌چین است.
محصولات، قیمت‌ها، موجودی و دسته‌بندی‌ها را زنده از WooCommerce Store API سایت zsdcp.ir می‌خواند.
برای خرید، صفحه محصول در Chrome Custom Tab باز می‌شود تا سبد خرید، ورود و درگاه‌های پرداخت فعلی ووکامرس حفظ شوند.

ساخت APK رایگان با GitHub Actions
---------------------------------
1) فایل ZIP را استخراج کن.
2) یک repository جدید در GitHub بساز (ترجیحاً Private).
3) تمام محتویات این پوشه را در ریشه repository آپلود کن.
4) به تب Actions برو و workflow با نام Build ZSD Android APK را اجرا کن.
5) بعد از موفقیت، در صفحه اجرای workflow بخش Artifacts فایل ZSD-Android-APK را دانلود کن.
6) ZIP خروجی Artifact را باز کن؛ فایل app-debug.apk داخل آن است.
7) APK را روی گوشی اندروید نصب کن.

هر بار تغییر کد را به branch اصلی push کنی، workflow دوباره APK می‌سازد.

نکات
----
- این پروژه به کلید API ووکامرس نیاز ندارد؛ از Store API عمومی مخصوص فروشگاه استفاده می‌کند.
- پرداخت در صفحات رسمی سایت انجام می‌شود؛ هیچ رمز یا کلید درگاه در اپ قرار نمی‌گیرد.
- برای انتشار در Google Play یا توزیع رسمی، بعداً باید نسخه release امضاشده با keystore ساخته شود.
- این اولین نسخه رابط اختصاصی است؛ فعلاً صفحه خانه/دسته‌بندی/جستجو بومی‌نماست و جزئیات خرید، ورود و سفارش‌ها در صفحات امن سایت باز می‌شوند.
- برای build، GitHub Actions استفاده می‌شود؛ سهمیه رایگان GitHub برای repository عمومی معمولاً مناسب است. برای repository خصوصی ممکن است محدودیت دقیقه رایگان حساب اعمال شود.
- از افزودن رمزهای سایت، کلیدهای API یا فایل keystore به GitHub خودداری کن.
